# 蒲公英 · 风过之处 — Remotion 复刻

用 [Remotion](https://remotion.dev) 以程序化 SVG 动画复刻的 34 秒竖屏动效短片（1536×2048，30fps）。

## 场景结构（对应参考片）

| # | 时间 | 场景 |
|---|------|------|
| 1 | 0–3.5s | 黑夜星空粒子流场 + 米黄色弧线焦点 |
| 2 | 3–8s | 雨中俯瞰池塘：白伞群、荷叶、雨丝涟漪 |
| 3 | 7.5–13.5s | 池塘纸伞漂流：麦穗岸边、睡莲、蜻蜓、虚线轨迹 |
| 4 | 13–18.5s | 麦田风起：蒲公英种子飘飞、飞鸟、红色花点 |
| 5 | 18–23.5s | 雨天落伞：奶油色云朵、飘落的伞与花瓣 |
| 6 | 23–29.5s | 草地蒲公英：橙蝶纷飞、种子四散 |
| 7 | 29–34s | 花草结尾：黄白野花随风摇曳 |

场景之间以约 0.9s 的交叉淡化衔接（开场为 2s 淡入）。

## 运行

```bash
npm install
npm run dev        # 打开 Remotion Studio 预览
```

## 渲染

```bash
npm run render     # 输出 out/dandelion.mp4
```

## 结构

- `src/Root.tsx` — Composition 注册（1536×2048，30fps，1020 帧）
- `src/Dandelion.tsx` — 全部场景组件与交叉淡化逻辑

无外部素材，全部画面由 SVG + Remotion 插值程序化生成。
